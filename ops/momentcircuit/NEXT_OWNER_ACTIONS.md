# MomentCircuit — Only the Owner Needs to Do These

Everything not listed here is delegated to the operator/agent workflow.

## Do now

1. **Create a fresh Google account for MomentCircuit**
   - Use it only for this media operation.
   - Keep the public profile pseudonymous.
   - Do not import contacts.

2. **Create TikTok + Instagram**
   - Brand name: MomentCircuit.
   - Use the closest available handle from:
     - @momentcircuit
     - @momentcircuit.media
     - @momentcircuitclips
     - @themomentcircuit
   - Use the dedicated media email.

3. **Immediately apply anonymity settings**
   - TikTok: turn off Contacts, Facebook friends, and “people who open or send links to you” account suggestions.
   - Turn off contact/Facebook syncing.
   - Remove previously synced contacts if any.
   - Deny iOS Contacts permission.
   - Instagram: do not add the account to the same Accounts Center as personal accounts; do not sync contacts.

4. **Create the YouTube channel**
   - Use the dedicated Google account.
   - Channel name: MomentCircuit.
   - No personal name/photo.

5. **Link the brand social accounts to Content Rewards/Whop**
   - Complete any OAuth/verification prompts.
   - Accept current Creator Terms if prompted.

6. **Complete payout/KYC privately if requested**
   - Legal name, tax, ID, bank/PayPal only inside the provider.

7. **For the first CoCo source package**
   - Open the official WeTransfer link from the campaign brief.
   - Agree to WeTransfer Terms/Privacy acknowledgement if you are comfortable doing so.
   - Do not manually edit/download/reupload anything else unless the operator asks.

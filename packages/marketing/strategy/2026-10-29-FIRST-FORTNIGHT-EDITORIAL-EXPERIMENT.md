## What to test FIRST (before producing the whole fortnight)

**First product-led pilot:** a genuinely interesting *recipe problem → actual adaptation → practical payoff* story, radically different from PR #104's static slides and PR #105's unrelated games. A specific diet, macro or headcount constraint, actual UI response, meaningful ingredient AND method change, no fabricated cooking outcome. Produce one short 9:16 story, one art-directed 4–6-card Instagram swipe alternative and one authentic X graphic/text variant. Make these **different editorial experiences**, not resized screenshots. Each must pass at phone size and use real product truth. If assets exist only as recorded historical fixtures, label them as such.

**Companion practical/fun test:** one ingredient/serving math explanation or one game/trivia graphic with a natural food-cook audience. Use this as a counterweight to promotional content, not a replacement for conversion work.

**An explanatory CTA:** use verified real RecipeFix landing/Adapt flow (do not assert an invented endpoint). Where posts cannot carry clickable outbound links, provide truthful profile-link guidance and track platform + variant UTMs if configured. Measure actual first-adaptation events; do not call a click conversion.

## Creative success and stop rules

- If the opening doesn't create a question/problem or reward, kill the concept before rendering.
- If visual changes are only text and static cards entering/exiting, reject; changing palette/font does not solve story.
- If the product is present but irrelevant to the story, the post fails the business objective.
- If a fun post is genuinely fun but has no product bridge, it may occupy a limited community slot and should be evaluated on relevant followers/engagement only.
- A post with a highly misleading product claim, fictional cooking result, fabricated label/measurement/recipe quality or incorrect licensing is never publishable.
- Actual founder response outranks automatic creative critics. Run actual muted/sound-on full playback; explicitly disclose any inability to hear audio quality.
- Record post idea ID, category, variant, cost, proof source, publication state, outbound link and actual metrics. Distinguish unknown from zero.
